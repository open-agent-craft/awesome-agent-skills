# AGENTS.md

## Project Context

This repository is a curated index of Agent Skills, AI coding skills, MCP recipes, tool-use patterns, and agent instructions.

## Working Agreements

- Keep entries practical, comparable, and source-backed.
- Prefer structured data changes in `data/skills.yml` over manual README edits.
- Run `npm run validate` after changing data.
- Run `npm run generate` after changing data.
- Include safety notes for resources that use tools, shell, files, browsers, credentials, databases, APIs, or external communication.

## Style

- Avoid generic descriptions.
- Explain why a resource is worth using.
- Keep maturity conservative.
- Do not include unsafe, spammy, or malicious resources.
