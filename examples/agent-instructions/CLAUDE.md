# CLAUDE.md

## Repository Purpose

This project curates reusable Agent Skills, coding workflows, MCP recipes, prompt patterns, and instruction formats.

## Contribution Rules

- Add resources to `data/skills.yml`.
- Reuse categories from `data/categories.yml`.
- Use maturity values: `recommended`, `promising`, `experimental`, `archived`.
- Regenerate README with `npm run generate`.
- Prefer concise, practical writing over marketing copy.

## Safety Rules

- Flag broad permissions.
- Do not include resources for credential theft, malware, spam, evasion, or abuse.
- Require human approval for destructive actions, publishing, messages, purchases, deployments, and production data changes.
