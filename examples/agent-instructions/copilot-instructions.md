# GitHub Copilot Instructions

This repository is an awesome list plus structured data source for Agent Skills and tool-use recipes.

When suggesting changes:

- Update `data/skills.yml` first.
- Keep `README.md` generated from data.
- Use existing categories and maturity labels.
- Include a concrete `why_awesome` sentence.
- Add `safety_notes` for any entry that uses tools, shell, files, browsers, credentials, databases, APIs, or external communication.
- Avoid generic copy such as "an AI assistant for coding."
