# Taxonomy

This taxonomy keeps the list searchable and comparable. Prefer adding a new tag before adding a new top-level category.

## Categories

### AI Coding

Skills and workflows for code review, test generation, bug fixing, refactoring, documentation, migration, architecture review, PR summaries, commit messages, and CI repair.

Common tags: `code-review`, `test-generation`, `bug-fix`, `refactoring`, `documentation`, `migration`, `architecture`, `ci-repair`.

### Research & Search

Research workflows for deep research, literature review, competitor analysis, market research, Reddit research, news digests, company research, and product comparison.

Common tags: `deep-research`, `literature-review`, `market-research`, `company-research`, `product-comparison`.

### Writing & Content

Skills for blog writing, technical writing, video scripts, social posts, product copywriting, release notes, documentation rewrites, translation, and SEO briefs.

Common tags: `technical-writing`, `script-writing`, `release-notes`, `translation`, `seo`.

### Data Analysis

Skills for CSV analysis, Excel analysis, chart generation, SQL analysis, BI dashboards, data cleaning, and report generation.

Common tags: `csv`, `excel`, `sql`, `dashboard`, `data-cleaning`, `report`.

### Browser Automation

Browser testing, screenshots, site QA, and web interaction recipes.

Common tags: `browser`, `playwright`, `screenshots`, `web-qa`, `computer-use`.

### Design & Media

Presentation generation, image prompting, UI review, brand guides, poster copy, and short-video storyboards.

Common tags: `presentation`, `image`, `ui-review`, `brand`, `storyboard`.

### Productivity

Calendar, email, todo, meeting, note, and knowledge-management workflows.

Common tags: `calendar`, `email`, `todo`, `meeting`, `notes`.

### DevOps

CI repair, release, deployment, infrastructure triage, observability, and operations recipes.

Common tags: `ci`, `deployment`, `release`, `observability`, `infra`.

### MCP & Tool Use

MCP servers, SDKs, function calling, tool routing, multi-step tool use, API calling, database query, file operations, and human-in-the-loop patterns.

Common tags: `mcp`, `function-calling`, `tool-routing`, `api`, `database`, `human-in-the-loop`.

### Agent Instructions

AGENTS.md, CLAUDE.md, GEMINI.md, copilot-instructions.md, Cursor rules, Windsurf rules, and project-specific instructions.

Common tags: `agents-md`, `claude-md`, `gemini-md`, `copilot`, `cursor`, `rules`.

### Evaluation & Testing

Skill evaluation, prompt evaluation, regression testing, benchmark loops, quality gates, and review workflows.

Common tags: `evals`, `regression`, `quality`, `benchmark`, `red-team`.

### Safety & Security

Prompt injection defense, tool permission, safe file operations, secret handling, human approval, and policy checks.

Common tags: `prompt-injection`, `permissions`, `secrets`, `approval`, `sandbox`.

## Maturity

Use one of:

- `recommended`: Practical, documented, reusable, and safe enough for most teams to evaluate first.
- `promising`: Useful and directionally strong, with gaps in examples, maintenance, or portability.
- `experimental`: Interesting early-stage work. Inspect before using in serious workflows.
- `archived`: Historically useful or educational, but no longer maintained or not recommended for new usage.
